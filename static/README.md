# 오세영 변호사 개인 홈페이지 — 정적 버전

React + Vite + Tailwind 로 만든 원본을 **디자인 · 화면 · 이미지 그대로** 두고
빌드 도구 없는 HTML / CSS / JS 구조로 옮긴 것입니다. 파일을 그대로 올리면 동작합니다.

```
static/
├── index.html          랜딩 원페이지 (히어로 → 해결사례 → 소개 → 원칙 → 업무분야
│                       → 칼럼·언론 → 절차 → 체크리스트 → 상담)
├── cases.html          해결사례 전체 아카이브 (연도별 그룹 · 분야 필터)
├── favicon.svg
└── assets/
    ├── css/style.css   디자인 토큰 · 조판 · 반응형 (sm 640 / md 768 / lg 1024)
    └── js/
        ├── data.js     해결사례 목록 — 실제 자료를 받으면 이 파일만 교체
        └── main.js     헤더 · 스크롤스파이 · 진입 모션 · 필터 · 아코디언
                        · 상세 오버레이 · 상담 폼
```

## 원본과 달라진 점

라우팅만 바뀌었습니다. 나머지는 마크업 · 색 · 여백 · 서체 · 모션까지 동일합니다.

| | React 판 | 정적 판 |
|---|---|---|
| 해결사례 전체 | `/cases` | `cases.html` |
| 분야 필터 | `/cases?category=성범죄` | `cases.html?category=성범죄` |
| 사례 상세 | `/cases/:id` (오버레이) | `?case=:id` (오버레이) |
| 칼럼 상세 | `/insights/:id` (오버레이) | `?insight=:id` (오버레이) |

상세는 원본과 같이 `history.pushState` 로 쌓기 때문에 **뒤로가기가 곧 닫기**이고,
주소를 직접 열어 들어와도 배경 위에 그대로 뜹니다.

## 내용 고치기

- **해결사례** — `assets/js/data.js` 의 `CASES` 배열. 연월 · 처분기관 · 죄명 · 처분결과
  네 항목이 필수이고, 해설을 붙일 사건에만 `detail` 을 답니다.
- **칼럼 본문** — `index.html` 맨 아래 `<template id="insight-…">` 블록.
  목록의 `<li class="insight-row">` 와 `data-id` 로 짝을 맞춥니다.
- **그 밖의 지면** — 소개 · 원칙 · 업무분야 · 절차 · 체크리스트 · FAQ 는
  `index.html` 에 그대로 적혀 있습니다.
- **초상 사진** — `index.html` 의 `.hero__portrait` 한 곳. 지금은 자리표시자(Unsplash)라
  실제 사진을 받으면 `src` 만 바꾸면 됩니다.

## 띄우기

정적 파일이라 별도 빌드가 없습니다. 로컬 확인은

```bash
cd static && python3 -m http.server 4321
```

배포는 디렉터리를 그대로 올리면 됩니다. 상담 신청 폼은 원본과 마찬가지로
아직 프런트엔드에서만 처리되므로, 실제 운영에서는 `main.js` 의 제출 지점을
메일 발송 API 로 연결해야 합니다.
